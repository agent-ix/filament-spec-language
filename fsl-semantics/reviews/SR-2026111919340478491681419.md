## Review notes

- The checked comparison test now evaluates `=`, `!=`, `<`, `<=` and Set self-equality over NaN and signed-zero snapshots. The expected-false cases assert `InvariantViolated`; expected-true cases only assert no violation, so an `InvariantUndetermined` result or missing clause result is not rejected.
- The snapshot decoder test now checks duplicate-set code, cause, field, earlier index and element path for both duplicate +0 and duplicate NaN. Malformed-bit, width, missing/extra-member, wrong-kind and wrong-slot cases still use `refusal_of`, which discards the diagnostic record details.
- The canonical-order assertion now compares an ordered `Vec<u64>`. `duplicate_member_indices` uses a width-and-bits `HashMap` path for Float values, making the reported large-Float uniqueness case linear; the non-Float fallback retains the shared membership relation.
- Focused builds/tests were not run, as the lead owns the batched check.
