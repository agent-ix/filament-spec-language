## Summary

Ticket: QSL-2716. PR filament-spec-language#3188, head 05eaf781303ac85284f19290c7267a5905c31d02, one commit, scope `git diff origin/main...HEAD` (11 files, +533/-27). Code-review with the rust-review lane folded in. The PR rebuilds a source `DomainPackage` from the package's source-object identity rows (`package_of_source_rows`, `BarePackage::source_model_package`). It declares the source object types in `world()` and passes the rebuilt package to `PackageModelInput::of`. It also removes the `UnreadModelForm::SourceObject` refusal for every consumer.

I checked the claims with a throwaway probe test in fsl-eval `it`, in a review worktree that was never committed. The probe ran three packages through the production `PackageModelInput::of` route. Single-unit Int[1, 3], Boolean and Integer parameters rebuild. Text and Decimal parameters refuse. Model-check input is compared against `ModelCheckInput::source`. A two-unit package is compared against S3.

## Verdict

NOT MERGEABLE.

- FND-001: lifting the refusal wholesale opens a silent soundness gap. It was reproduced.
- FND-002: on a two-unit package the read-back is not equal to S3. It was reproduced.
- FND-003: a common scalar parameter now turns a located pending refusal into an unlocated internal fault in fsl-analyze.

What holds: the single-unit join is right. The declaration keys `source/<pkg>` and `ix://source/<pkg>/<Type>` match S3's `node_key`. The supertypes resolve by row node. Clock parameters map to `ValueTypeRef::Clock`. The AC-6 literal `k: Int[1, 3]` parses through `rendered_scalar` (probe: one random parameter and the workload rebuilt). The two new tests assert real equality against S3's checked records. The diff has no `#[allow]`, no shims and no tmp/ or target/ files. The trace tags use real ACs.
