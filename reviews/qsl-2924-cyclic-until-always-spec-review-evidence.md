## Summary

## Verdict

Every number in AC-58..63 was hand-verified. AC-58: Pr(always)=1/2; `>= 1/2` union {t}, s=1/2,t=1,u=0 (u Prob0), ranks 1,0,0, 1/2 <= 1/2; `<= 1/2` union {u}, t=0; `>= 3/5` needs v <= 2/5 and `<= 2/5` needs v <= 2/5, both fail; all-one values fail only at u (non-target BSCC); empty targets mismatch {u}. AC-59: Pr(until)=1/4; `>= 1/4` union {n,c,d}, reached targets {c,n}, s = 1/4+1/2 = 3/4, d unreached, 3/4 <= 3/4; `<= 1/4` union {b}, s=1/4; 7/10 and 1/5 fail; rank 2 is not the shortest distance 1; the {n} document is harmonic (s = 1/4) and passes 1/4 <= 1/2 but mismatches {c,n}. AC-60: min 1/2 (b), max 3/4 (a); `>= 1/2`: Q_a = 1/4, Q_b = 1/4+1/4 = 1/2 tight; `<= 3/4`: Q_a = 3/4 tight, Q_b = 3/8+1/4 = 5/8; 3/5 and 7/10 fail; s=1/4 gives Q_b = 1/8+1/4 = 3/8 > 1/4 (claim `>= 3/4` false since min = 1/2); rank 0 at positive s breaks. AC-61(i): MEC {s}/wait rejecting, s initial target value 1 > 1/2, min = 0; empty-target zero vector satisfies max Bellman but mismatches. AC-61(ii): {ok}/stay accepting, max 1; `>= 1/2` targets {down}, ok = 1 via leave, 1 > 1/2; ok = 0 fails Q_leave = 1. AC-62's values 1/4 and 1/2 are the claim values (documents carry 3/4 and 1/2), consistent. TCs match their ACs except TC-3181's combined check. No AC/TC id collision with open PRs (#3546, #3548, #3549, #3550, all other open PRs scanned). Mergeable once FND-001/002 are fixed.
