## Summary

Ticket: QSL-2935. Spec-only PR, reviewed as `git diff origin/main...HEAD` at e25a201bf28cfa58f9d68a23d94a697c59797ec4; quire validate over the five touched files exits 0. No cargo was run.

Checked that FR-1047 states each rule once, that FR-620 and FR-027 only point to it, that FR-620-AC-9 is unchanged, that the FR-027-AC-2 change follows from FR-1047 and weakens nothing, that the entry table and one-of groups match fsl-command/src/command.rs and wire.rs, and that no other requirement, test case or the merged driver PR agent-ix/filament-driver#248 contradicts it. FR-620's bullet now points to FR-1047 and AC-9 is byte-identical to main. Given FR-1047's rule that no entry refuses a request format unknown_wire, the change is necessary. native-export/1 appears nowhere in code (export.rs:142-145 requires native-run/1). Monitor and replay dispatch through run is as the code does it (command.rs:2037-2044: is_monitor_request and is_replay_request peek format first). models is serde-required in native-run/1 (wire.rs:283) and optional in analyze and compile; monitor requires models, program, clauses, trace (wire.rs:951-965), matching AC-3; Identity field order authority, identity, document, formal_revision (wire.rs:625-630) matches AC-4. Existing tests asserting the old behaviour: tests/it/compile_command.rs:97-98 (unknown_wire/envelope, FR-027-AC-2), fsl-command/tests/it/cli_contract/compile.rs:266-267 (native-compile/9 to unknown_wire), and fsl-command/tests/it/export_selection.rs:139 (asserts 'requires export', not listed in the PR body). IDs FR-1047 and TC-3170 collide with nothing on main or on open PRs (#3546 uses TC-3162..3165 and TC-3171..3172; #3547 and #3549 add no FR-1047/TC-3170).
