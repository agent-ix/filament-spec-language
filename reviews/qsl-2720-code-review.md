## Summary

Ticket: QSL-2720. PR #3243 at head `ee514b35` (rebased on main `d84ed5685b`) adds a `break` after the refusal push in two S3 lowering loops of `PackageDeclarations` in `fsl-semantics/src/check/mod.rs` (composites at 6799-6806, enums at 6822-6828) once `cancel.tripped()` is set, and un-ignores the FR-276-AC-2 test. The rust-review lane (rust-style baseline, cancellation and resource-bound sections) is folded into this file.

## Verdict

CONDITIONAL — one medium finding to fix in this PR, one low.

What holds:

- The enum-loop `break` bounds the scenario the AC tests. `Cancel::poll` (filament-exact `b26a8e4`, `src/cancel.rs`) calls the observer before it reads the state, so the charge-1,000 observer's synchronous trigger/ack rendezvous records `Deadline` before charge 1,000 reads it; charge 1,000 is denied, `enum_nodes` refuses, the loop breaks. On main the loop keeps calling `enum_nodes` for the remaining enums, one denied charge each, so the 1,000..=1,001 oracle fails on the old code.
- The pushed refusal is discarded correctly: `check_with_cancel` returns `Err(refusals)` unchanged when `cancel.tripped()` is set (mod.rs:2259), and the spine maps a tripped handle to `StageFailure::Cancelled(cause)`; the test asserts `Cancelled(Deadline)`, no `Ok`, and `tripped() == Some(Deadline)`.
- The test is deterministic: `sync_channel(0)` rendezvous both ways, no clock or sleep, the source is generated by a fixed loop of 200,000 `enum E{i} { A, B }` lines, and the raised S1/S3 bounds are derived from the source's own byte length. Weak `trigger` plus `drop(trigger_owner)` lets the listener exit if charge 1,000 never arrives, so a regression fails by assertion, not by hang.
- `#[trace("FR-276-AC-2")]` is a bare FSL id. No match arms, panics, Cargo.toml or Cargo.lock changes; no gate narrowed.

## Findings detail

- **FND-001.** Failure scenario: a document with many records (composites) and at least one enum, cancelled while the composite loop runs. The composite charge that sees the handle is denied and the loop breaks, but the function continues: `model_type_unit_nodes` and `declared_nominal_nodes` charge per unit, the enum loop charges the first enum before its own `break`, `dimension_equivalence_nodes` charges per equivalence, and the class-catalog and refinement-row loops (6838-6879) charge per refinement with no break at all. Earlier loops in the same function — terminals (6720), urgency predicates (6743), timed clauses (6784), hyper clauses, state-graph claims, hybrid models and claims, extension forms — still push and continue. Each writes nodes through the same insertion path whose node charge denied `enum_nodes` (traced for `enum_nodes`; inferred for the others, not run). Every one of those charges is denied and observed, so the observer counts at least two charges after cancellation for composites+enums and an unbounded number for large refinement or terminal sets. FR-276 Behavior: "When the handle is cancelled, each lifecycle operation shall stop at its next charge"; AC-2's literal case passes only because nothing after the enum loop is populated in its source. The rest of `check/mod.rs` already uses the shape that does stop (`if cancel.tripped().is_some() { return Err(refusals); }`, e.g. 5049-5051, 5060-5062, 5394-5407). **Fix:** replace both `break`s with `return Err(refusals)`, and apply the same tripped-return after each `refusals.push` in the other lowering loops and single calls of this function (a small local helper or a check at each push site), so the stage ends at the denied charge.
- **FND-002.** **Fix:** add the composite path to the test (for example a second case generating `record R{i} { x: Integer }` declarations, or mixed records then enums, which also covers FND-001's cross-loop case) with the same 1,000..=1,001 bound.
