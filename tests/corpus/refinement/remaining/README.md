# Projection and execution source cases

The nine runnable cases compile original projection-aligned hyperproperties, protocol-selected refinements and relations over operation executions. Their model input references the existing counter-step package in this repository.

The projection source binds a skipped operation, an ordered pair of quantified traces and a step match. Repeating an operation, naming an unresolved skipped operation or adding fairness to projection alignment produces the defined expression-form refusal.

A protocol refinement selects its concrete protocol through a finish-step row. The emitted class catalogue retains that finish and its stutter mapping. Naming a protocol in the concrete header and naming an absent finish step are independent source refusals.

An execution relation compares the pre-state and post-state of two calls to the same operation. A non-Boolean relation body refuses. The tests compile through the public source command and inspect the emitted semantic nodes. The source-expectation group and protocol emission check pass; two projection/relation reference-resolution oracles remain pending under QSL-2609 because emitted internal targets are absent.

`projection-empty-skip` covers QSL-2599: the grammar admits the empty list and S3 refuses it at the whole `align skip { }` item. Finite trace-domain admission and whole-model clauses remain under QSL-2239 and QSL-2248; their authored examples are recorded in those owning tickets. Hyper analysis remains under QSL-2128. None of those blocked families is claimed by this slice.
