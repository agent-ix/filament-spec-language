# Projection and execution source cases

The nine runnable cases compile original projection-aligned hyperproperties, protocol-selected refinements and relations over operation executions. Their model input references the existing counter-step package in this repository.

The projection case retains its skipped operation, quantifier order and step match in the emitted hyperproperty. Repeating an operation, naming an unresolved skipped operation or adding fairness to projection alignment produces the defined expression-form refusal.

A protocol refinement selects its concrete protocol through a finish-step row. The emitted class catalogue retains that finish and its stutter mapping. Naming a protocol in the concrete header and naming an absent finish step are independent source refusals.

An execution relation compares the pre-state and post-state of two calls to the same operation. Its emitted receivers remain distinct; a non-Boolean body refuses. The tests compile through the public source command and inspect the emitted semantic nodes.

`pending/projection-empty-skip` belongs to QSL-2599: its grammar and semantic-stage contracts disagree. It contributes no passing coverage. Finite trace-domain admission and whole-model clauses remain under QSL-2239 and QSL-2248; their authored examples are recorded in those owning tickets. Hyper analysis remains under QSL-2128. None of those blocked families is claimed by this slice.
