# Temporal source cases

The standalone programs run through `source_corpus::corpus_temporal`. Each
invalid program targets one syntax or semantic error; `operators.native`
supplies bounded-until, nested liveness and derived-next clauses for real trace
evaluation in `temporal_package_route::source_journeys`.

The same integration module runs the 22 rover temporal requests directly from
their authoritative repository. Set `FSL_EXAMPLES_DIR` to a filament-examples
checkout before running those tests; a missing checkout is an error. Source,
requests, models and observations remain in that repository. The tests assert
explicit verdicts rather than deriving expected results from recorded output.

The finite recording that already contains a stop remains pending for the
global safe-stop rule: a later extension could still violate it. Bare `next`,
`previous` and `weak until` are not surface grammar keywords; derived next is
`eventually[1,1]`.
